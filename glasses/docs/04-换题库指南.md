# 换题库指南（给不懂编程的人看）

一句话流程：**电脑把题库变成一个网址 → 把这个网址做成二维码 → 眼镜扫一下 → 换好了。**

眼镜上有摄像头，所以「扫」这一步交给眼镜做，手机完全不用参与。

---

## 一、最快的一条路（电脑和眼镜同一个 WiFi）

### 第 1 步：电脑上运行一行命令

```bash
python glasses/tools/serve_bank.py 题库合并.json
```

屏幕上会自动弹出一张二维码，命令行里会打印类似：

```
  题库：题库合并.json（1,902,148 B）
  地址：http://192.168.0.101:8899/qbank.json
  二维码：glasses/shots/qr_bank.png

  眼镜上：主界面 长按 → 单击，进入扫码页，对准这个二维码。
```

**这个窗口不要关**，关上服务就停了。

### 第 2 步：眼镜上打开扫码页

眼镜只看不点，操作全靠镜腿上的触摸板：

1. **长按**触摸板 → 进入「调试」页
2. **单击**触摸板 → 进入「扫码换题库」页

### 第 3 步：对准二维码

举着眼镜看向电脑屏幕，距离 20～30 厘米，让二维码完整落在画面中间。

屏幕会依次显示：

```
正在下载   3xx KB
正在编译
已更换
2026年公路水运试验检测题库（道路工程＋公共基础）
6622 题 · 933 KB · 1.7 秒
```

**不用重启应用，不用重新安装。** 双击触摸板回到主界面，直接开始拍题就有了。

---

## 二、不在同一个网络怎么办（公网地址）

只要题库文件有一个**能直接下载的网址**，不管它在哪，流程都一模一样：

```bash
python glasses/tools/serve_bank.py --url https://example.com/bank/qbank.json
```

同样弹出二维码，眼镜那边操作完全不变。

常见的放法：

| 方式 | 得到的地址长什么样 |
|---|---|
| 对象存储（阿里云 OSS / 腾讯云 COS 等） | `https://xxx.oss-cn-hangzhou.aliyuncs.com/qbank.json` |
| GitHub 仓库的 Raw 链接 | `https://raw.githubusercontent.com/…/qbank.json` |
| 自己的服务器 / 内网穿透 | `https://你的域名/qbank.json` |

⚠️ 必须是**文件直链**——浏览器打开就直接开始下载的那种。
网盘（百度网盘、阿里云盘）的「分享链接」不行，打开的是网页，不是文件。

---

## 三、电脑上没有 Python 也行

二维码里装的只是一个网址，所以任何能把网址变成二维码的工具都能用：
微信「扫一扫」里的生成功能、在线二维码生成器、手机上的二维码 App 都行。

只要保证**二维码的内容就是那个文件直链**即可。

## 四、支持哪些题库文件

| 扩展名 | 说明 | 建议 |
|---|---|---|
| `.json` | 题库源文件（就是 PC 端那个 `题库合并.json`） | **推荐**，自带题库名，眼镜现场编译，约 3 秒 |
| `.idx` | 已编译好的索引（`build_qbank.py` 的产物） | 传得快、装得快，但不带题库名，只显示文件名 |

大小上限 40 MB。题库换完存在应用自己的目录里，**卸载应用才会清掉**。

## 五、常见问题

**扫了半天没反应？**

- 看页面底部那行「识别中 N 帧/秒」：数字是 0 说明摄像头没出画面（换个亮一点的地方）；
  数字有 3～15 说明识别在跑，那就是没对准或者二维码太小
- 二维码别贴在屏幕边缘，周围留点白边
- 眼镜屏幕只有绿色，黑底白块最清楚，别用彩色渐变风格的二维码

**扫到了但下载失败？**

界面上会直接给原因：

| 提示 | 意思 |
|---|---|
| 域名解析失败 | 眼镜没联网，或网址里域名拼错 |
| 连接超时 | 地址不通：不在同一 WiFi，或路由器开了「AP 隔离」 |
| 404 文件不存在 | 网址指向的位置没有这个文件 |
| 文件只有 xxx 字节，不像题库 | 拿到的是网页/报错页，不是题库文件 |
| 证书校验失败 | https 站点证书不对，换 http 或换地址 |

**怎么确认真的换成功了？**

长按进「调试」页，看「自检」那一行：
显示「通过 · top1=#0 @1.00」才算可用；显示「失败 · …」说明索引有问题，重新换一次。

**换完题数没变？**

说明新文件里题目本来就少（比如只有 200 题），看页面显示的题数对不对即可。
替换不是追加，旧题库不会留下来。

**想换回原来的题库？**

再扫一次原来的文件就行。实在没留文件，卸载重装就回到内置题库。

**不联网能不能换？**

能，但要会用命令行：把文件推进去，重启应用会自动发现。

```bash
adb push 题库合并.json /sdcard/Download/
```

## 六、为什么是这个方案

这副眼镜折腾题库，试过的路和各自的死穴：

| 方案 | 为什么不行 |
|---|---|
| 当 U 盘拖文件（MTP） | USB 只暴露 adb，`sys.usb.config` 恒为 `adb`，系统里没有 MTP 通道 |
| 蓝牙传文件 | 系统里没有任何应用能接收 `application/octet-stream`，发过去无处可落 |
| 眼镜上装文件管理器 | 480×640 单绿屏 + 触摸板，选文件这一步本身就很难用 |
| 眼镜屏幕上显示二维码给手机扫 | 那是投影画面，手机摄像头拍不清楚 |
| 手机浏览器上传到眼镜开的网页服务 | 要手机和眼镜同网、要手输/扫地址，多一个中间环节 |

最后落在「**眼镜扫二维码**」上：这副眼镜本来就有摄像头，扫是它的本职工作；
而二维码里装的是一条网址，这条路能同时覆盖局域网和公网，还能顺带兼容任何题库托管方式。
